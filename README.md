# Islamic-widget
This is an Islamic inspired Rainmeter widget for anyone who would like to decorate their PC and give an aesthetic and please look. This file was created purely using claude and i would like for you to try it and make Dua for me.

HOW TO USE:
1. First download Rainmeter using this link: https://www.rainmeter.net/
2. Next step go these files: Rainmeter > Skins then add the files to the skins folder
3. Go to Rainmeter and click refresh and you will find the files there
4. Finally, click on each file and click on the .ini files and click load
5. Enjoy your widget!
